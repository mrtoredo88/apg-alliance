# АПГ Android 1.3.1 (10301)

Дата подготовки: 28 июля 2026 года.

## Изменения

- Удалено разрешение `android.permission.REQUEST_INSTALL_PACKAGES`.
- Удалён встроенный механизм загрузки и установки APK.
- Обновление приложения теперь открывает внешнюю страницу обновления и не запрашивает право устанавливать приложения из неизвестных источников.
- Добавлена автоматическая проверка, не допускающая возврат запрещённого разрешения в Android manifest.

## Причина выпуска

Версия 1.3.0 (10300) была отклонена модерацией RuStore из-за разрешения
`REQUEST_INSTALL_PACKAGES`. Версия 1.3.1 подготовлена для повторной отправки
после полного удаления разрешения и связанного нативного установщика.
