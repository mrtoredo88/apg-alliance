# APG: исправление нижней навигации

База: 23d0c37d (последний локальный коммит основной рабочей копии).
Ветка: fix/mobile-island-navigation.

## Изменения

- Удалён независимый SWIPE_TABS с ошибочным третьим пунктом experts.
- Основные разделы определяются через USER_MODE_NAV_ITEMS; жесты между ними отключены, включая возврат от края. Вложенные экраны сохраняют edge-back.
- Кнопка «Афиша» использует существующий panelId events. Экран Экспертов не изменён.
- Основные URL синхронизированы с React Router, добавлены /offers и /profile, back/forward восстанавливают активный раздел. Активная кнопка имеет aria-current.
- Горизонтальные карусели и pull-to-refresh сохранены.

## Проверки

Пройдены: lint четырёх изменённых JS/JSX/MJS-файлов; mobile-island-navigation-test (16 случаев); test:pull-refresh; test:partner-deeplink; test:desktop-events; production build.
Браузерный тест проверяет четыре кнопки, историю назад/вперёд, шесть прямых/hash URL, /experts, прокрутку трёх каруселей настоящими touch-событиями Chromium (390×844).

Общие проверки проекта не чистые: npm run lint выдаёт 117 ошибок; test:workspace-layout падает на старой проверке canonical asset Локи. Файлы Локи и этот тест не изменены. Эти ошибки не исправлялись вне рамок задачи.

## Выпуск

Production не изменён. Сборка dist подготовлена локально; перед публикацией нужно устранить общие блокеры проверок и сверить базу с фактически развёрнутым релизом. Изменения чужих незавершённых задач не включены.
После переноса коммита в релизную ветку собрать заново: version.json должен содержать hash релизного коммита. Использовать штатный deploy-frontend.sh после прохождения проверок.
